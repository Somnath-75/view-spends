# View Spends

A minimal spending tracker for everyday life.

## Downloads

- [Download the signed Android APK (v1.0.2)](https://github.com/Somnath-75/view-spends/releases/download/v1.0.2/View-Spends.apk)
- [Download the complete Android source (v1.0.2)](https://github.com/Somnath-75/view-spends/releases/download/v1.0.2/View-Spends-Android-Source-v1.0.2.zip)
- [View release notes](https://github.com/Somnath-75/view-spends/releases/tag/v1.0.2)

The Android app is offline-first and keeps records on your device. Version 1.0.2 waits for local recovery before setup appears and maintains a second private app storage copy. Swiping the app away from Recent Apps should preserve records; Android Clear storage or uninstalling removes all local data. Export a JSON backup before reinstalling or moving to another device.

## Edit and build

Download and extract the source archive above, then follow its README.md. Anyone is welcome to fork the repository, edit the source, and contribute improvements. The app is MIT licensed. Please do not publish personal spending records, signing keys, or passwords.
