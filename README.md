# View Spends

A minimal spending tracker for everyday life.

This public project includes the complete Android app source, build scripts, and contributor guide in the archive below. It is offline-first, stores spending records on your device, and has no AI, analytics, account service, or network permission.

[Download the complete Android source archive](https://github.com/Somnath-75/view-spends/raw/refs/heads/main/View-Spends-Android-Source.zip)

## Edit and build

1. Download and extract the source archive.
2. Open the folder you extracted in your editor.
3. Follow its README.md for requirements and debug/release APK build steps.
4. Read [CONTRIBUTING.md](CONTRIBUTING.md) before sharing changes.

Anyone is welcome to fork this public repository, edit the source, and contribute improvements. The app is MIT licensed. Please do not publish personal spending records, signing keys, or passwords.

## Privacy and sync

Spending data stays in the app's private storage. There is no account or automatic cross-device sync; move records between devices with an exported JSON backup.
