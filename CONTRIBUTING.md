# Contributing to View Spends

Contributions from any coder are welcome. You can fork this repository, make a change, and open a pull request for review.

## Before opening a pull request

1. Install Node.js 22+, pnpm, Java 21, and Android SDK Platform 36 with Build Tools 36.0.0.
2. Run `pnpm install`.
3. Run `pnpm test` and `pnpm run build`.
4. Describe what changed and how you checked it.

Please keep this app offline-first. Do not commit personal spending records, account credentials, signing keys, or passwords. Changes that add network access or collect data should be discussed in an issue before implementation.
